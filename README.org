* Overview

This is my personal knowledge base — a collection of notes on computer science,
programming languages, machine learning, and other topics. Notes are written in
Org-mode and published as a static website via GitHub Pages at
[[https://base.silinzhao.com]].

* Structure

- ~*.org~ — Source notes (Org-mode format)
- ~html/~ — Exported HTML pages (generated by =build.sh=)
- ~templates/~ — HTML template and CSS for the site
- ~categories.js~ — Sidebar navigation data (auto-generated)
- ~index.html~ — Main entry point with sidebar tree and iframe viewer
- ~build.sh~ — Build script that exports Org → HTML and generates the index

* How to Update

** Add a new note

Adding a new note involves 3 steps — create the file, register it in a
category, then rebuild:

*** 1. Create the =.org= file

Create =MyNewTopic.org= in the root directory with at minimum these headers:

#+begin_src org
,#+TITLE: My New Topic
,#+EXPORT_FILE_NAME: html/MyNewTopic.html
#+end_src

The ~#+EXPORT_FILE_NAME~ tells the build script where to place the exported
HTML. It must follow the pattern =html/<Name>.html= — the =<Name>= part
(without =.html=) is the identifier used in the next step.

*** 2. Register the note in a category

Edit =build.sh= and add the note name (the filename without =.html=) to the
appropriate category in the ~CATEGORIES~ list:

#+begin_src python
CATEGORIES = [
    ("Computer Science",       "Linux Algorithm MyNewTopic".split()),
    ...
]
#+end_src

The name you add here must match the HTML filename (without =.html=).  For
example, if ~#+EXPORT_FILE_NAME: html/MyNewTopic.html~, add ~MyNewTopic~ to the
desired category.

*** 3. Rebuild

#+begin_src bash
./build.sh
#+end_src

This exports all =.org= files to =html/*.html=, regenerates =categories.js=,
and rebuilds =index.html= from the template.

** Edit an existing note

Edit the =.org= file and run =./build.sh= to re-export the HTML.

** Categorize an uncategorized note

Edit =build.sh= and add the note name to the appropriate category, then run
=./build.sh=.

* How to Deploy

** GitHub Pages (automatic)

Push to the ~main~ branch:

#+begin_src bash
git add .
git commit -m "Update notes"
git push origin main
#+end_src

The site is served at [[https://base.silinzhao.com]] via GitHub Pages (CNAME
configured).

** Local preview

#+begin_src bash
./build.sh
open index.html
#+end_src

* Requirements

- [[https://www.gnu.org/software/emacs/][Emacs]] with org-mode (for =org-html-export-to-html=)
- Python 3 (for generating =categories.js=)
- Perl (for pre-processing org files during build)

* Customization

** Change category names and note grouping

Edit the ~CATEGORIES~ variable in =build.sh=:

#+begin_src python
CATEGORIES = [
    ("My Category Name",  "Note1 Note2 Note3".split()),
]
#+end_src

** Change styling

- =templates/org-export.css= — Note page styling (content width, colors, fonts, TOC sidebar)
- =templates/index.template.html= — Index page styling (sidebar colors, layout, theme)
- =html/style.css= — Generated from =templates/org-export.css= at build time

** Add external links

Edit the ~EXTERNAL_LINKS~ variable in =build.sh=:

#+begin_src python
EXTERNAL_LINKS = [
    ("Blog", "https://blog.example.com/"),
]
#+end_src
